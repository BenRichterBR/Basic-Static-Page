# Basic Static Page

This is a static webpage to showcase my proficiency with HTML, CSS, JavaScript, and Bootstrap 5. It interacts with the sessionStorage API and sets simple cookies.




## Installation

No installation needed. Simply go to https://benrichterbr.github.io/Basic-Static-Page to view.

No information about you or your browser is stored by this application.
